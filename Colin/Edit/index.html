Comment ça marche

Texte — clique n'importe quel texte pour l'éditer directement.

Survole une image, un lien ou une carte projet pour voir apparaître un petit badge d'action. Un clic dessus fait exactement une chose (changer la photo, modifier le lien, supprimer...).

Réseaux sociaux — survole une icône pour changer son lien ou la supprimer ; un "+" à la fin de la liste en ajoute une nouvelle.

Projets — chaque carte s'édite directement (image, titre, corps de métier, texte, lien). Le bouton "+ Projet" en haut en ajoute une nouvelle ; la croix sur une carte la supprime.

Couleurs — les 4 nuanciers "Couleurs" changent la palette du site en direct, séparément pour le thème clair et sombre (bascule le thème avec le rond ☀/☾ en haut de la barre latérale du site pour régler les deux).

FR / EN — bascule la langue directement sur le site (bouton FR/EN dans la barre latérale) : tu édites alors le texte anglais. Chaque langue est stockée séparément, rien n'est écrasé.

Ctrl+Z annule ta dernière modification.

Sauvegarde auto — le brouillon est stocké dans ton navigateur. Si l'indicateur en haut à droite passe en rouge, télécharge le site pour ne rien perdre.

Télécharger le site — génère un index.html propre (sans les outils d'édition) à uploader sur GitHub par-dessus l'ancien.
