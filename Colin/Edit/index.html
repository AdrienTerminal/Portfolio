Comment ça marche

Texte — clique n'importe quel texte pour l'éditer directement.

Survole une image, un lien ou une carte projet pour voir apparaître un petit badge d'action. Un clic dessus fait exactement une chose (changer la photo, modifier le lien, supprimer...).

Modules (Accueil / Qui suis-je / chaque page de détail projet) — ces zones sont entièrement personnalisables : Titre, Texte, Tags, Liste, Stats, Image (JPG/PNG/GIF, l'animation est conservée), Lien, Vidéo (lien YouTube ou fichier MP4). Utilise les boutons "+" en bas de chaque section pour en ajouter, la croix sur un module pour le supprimer. Maintiens la poignée ⠿ (en haut à gauche du module, au survol) pour le déplacer : les autres modules se réorganisent en direct autour ; relâche pour valider, ou fais un clic droit pendant le déplacement pour annuler.

Réseaux sociaux — survole une icône pour changer son lien ou la supprimer ; un "+" à la fin de la liste en ajoute une nouvelle.

Projets — chaque carte s'édite directement (image, titre, corps de métier, texte). Le bouton "Voir plus" ouvre une grande page de détail dédiée à ce projet, avec son propre système de modules (comme Accueil / Qui suis-je) — clique "Voir plus" pour l'éditer, "← Retour aux projets" pour revenir à la grille. Le bouton "+ Projet" en haut ajoute une nouvelle carte (avec sa page de détail) ; la croix sur une carte supprime les deux.

Couleurs — les 4 nuanciers "Couleurs" changent la palette du site en direct (un seul thème, sombre).

FR / EN — bascule la langue directement sur le site (bouton FR/EN dans la barre latérale) : tu édites alors le texte anglais. Chaque langue est stockée séparément, rien n'est écrasé.

Ctrl+Z annule ta dernière modification.

Sauvegarde auto — le brouillon est stocké dans ton navigateur. Si l'indicateur en haut à droite passe en rouge, télécharge le site pour ne rien perdre.

Télécharger le site — génère un index.html propre (sans les outils d'édition) à uploader sur GitHub par-dessus l'ancien.
